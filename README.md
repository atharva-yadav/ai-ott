# CineGPT - AI that senses your taste

An OTT (Over-The-Top) streaming application with AI integration.

## Overview

AI-OTT is a modern streaming platform that leverages artificial intelligence to enhance the experience. This project combines traditional OTT functionality with AI capabilities.

## Features

### 🔐 Authentication
- **Login / Sign Up**
  - Sign In and Sign Up page
  - Secure authentication flow
  - Redirects to the **Browse** page after successful login


### 🎬 Browse Experience
- **Browse Page** *(Accessible after authentication)*
  - **Header**
    - Navigation and user controls
  - **Hero / Main Movie Section**
    - Auto-playing trailer in the background
    - Movie title and description
    - Personalized movie recommendations
      - Multiple curated movie lists


### 🤖 CineGPT (AI-Powered Discovery)
- **Smart Search Bar**
  - AI-assisted movie search
- **Intelligent Movie Suggestions**
  - Context-aware and preference-based recommendations
